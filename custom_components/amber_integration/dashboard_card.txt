Amber Dashboard - Manual Entity Groups
=======================================

This is a reference for building your own dashboard by hand, as an
alternative to the auto-installed one (which can't be edited in the UI -
see "Using the Dashboard Card" in the README).

For each group below, add an Entities card
(your dashboard -> Edit Dashboard -> Add Card -> Entities) and include the
listed entities. One card per group is the simplest starting point - group
them differently, split them further, or leave groups out entirely to suit
your own setup. Unlike the auto-installed dashboard, cards built this way
are fully editable in the UI afterwards: reorder, rename, restyle, whatever
you want.

POWER (optional)
-----------------
Point these at your own existing sensors to add a Power group (battery,
solar, load, grid). All optional and blank by default - leave any of them
empty and that reading just doesn't appear. Battery level has its own
fallback to Amber's own reading if you don't set it.

text.amber_smart_shift_power_battery_level_sensor
